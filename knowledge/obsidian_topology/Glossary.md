# Glossary - Network Operations Terms

A reference database of protocol terms, custom service names, and multi-vendor commands used in the NETAct workspace.

## Protocols
- **BGP:** [[BGP]] — Border Gateway Protocol. Used for edge transit and L3VPN peerings.
- **OSPF:** [[OSPF]] — Open Shortest Path First. Internal gateway protocol for core reachability.
- **MPLS:** [[MPLS]] — Multi-Protocol Label Switching. Transport engine for tunnels.

## Commands Reference
- **Cisco IOS-XE/XR `show`:** View diagnostic state (e.g. `show ip ospf neighbor`).
- **Huawei VRP `display`:** View diagnostic state (e.g. `display bgp peer`).
- **Juniper Junos `show`:** View diagnostic state (e.g. `show bgp neighbor`).
